# RAM Construction Charleston · homepage comp and assets

Static homepage comp for ramconstructionsc.com (RAM Construction Charleston, a division of RAM Construction, Charlotte NC).
`index.html` is the single-file source of truth for the Lovable build. `img/w/` holds the web-sized images
(generated Lowcountry scenes, declared illustrative on the page, and RAM Charlotte project photographs),
`img/brand/` the black-and-white RAM mark, `img/cred/` the credential marks. Built by ByteZero, 2026-09.
